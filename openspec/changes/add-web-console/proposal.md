## Why

У бэкенда нет HTTP-поверхности вообще: presentation-слой сейчас — только `EveTrader.Cli`.
Пока данные смотрит один человек через терминал, этого достаточно; как только появятся
сигналы и результаты бэктестов, терминал перестаёт справляться — рыночные данные
читаются графиками, а не таблицами в консоли.

Изменение заводится **заранее и осознанно не стартует сразу**. Причина: интерфейс — большая
поверхность, конкурирующая за время с единственным, что производит ценность, — моделями и
сигналами. Пока показывать нечего кроме отчёта о покрытии, CLI печатает его дешевле.
Смысл записать предложение сейчас — зафиксировать решения, которые иначе придётся
принимать в спешке: форму API, разделение процессов и выбор графиков.

**Предварительное условие.** Изменение не может быть реализовано до
`add-market-observation-pipeline`: без озера фактов и журнала покрытия читать нечего.
Начало работ дополнительно обусловлено появлением первых сигналов — до этого экраны рынка
не имеют содержания.

## What Changes

- **Отдельный процесс API только для чтения.** `EveTrader.Api` в `src/presentation/`
  поднимается и падает независимо от коллектора и в озеро не пишет. Это работает
  бесплатно благодаря уже принятому определению: факт — строка, подтверждённая записью
  покрытия, поэтому читатель не видит недописанных партиций, а параллельное чтение
  Parquet другим процессом ограничений не имеет.
- **Форма API — minimal API, не MVC.** `csharp/api-design.md` относится только к
  проектам с контроллерами; для read-only консоли контроллеры — церемония. Контракт
  описывается OpenAPI, TypeScript-клиент генерируется из него, а не пишется руками.
- **Веб-консоль на зафиксированном стеке** из `.agents/rules/typescript/`: React 19 +
  Vite + bun + Tailwind 4 + Base UI/shadcn + TanStack Query/Router + i18next. Выбора
  здесь нет — это канон владельца, общий для всех его фронтендов.
- **Графики** — единственное, что правилами не покрыто (их бэклог перечисляет формы,
  тесты, кодоген, zustand; графиков нет). Решение: `lightweight-charts` основной
  библиотекой, `uplot` — только если появится ряд, который тот не тянет, тепловая карта
  глубины при необходимости своим canvas. `recharts` не используется: он рисует SVG и
  умирает на тысячах точек, а у нас ряды на сотни тысяч.
- **Экраны рынка**: обзор, детализация по паре «тип и локация», ценовые и объёмные
  графики по дневной истории, спред и глубина по признакам стакана.
- **Экраны состояния**: покрытие с тремя состояниями, реестр материализации, здоровье
  сбора и расход бюджета ошибок.

**Non-goals.** Любые пишущие пути — консоль только читает; авторизация и многопользо­
вательский режим (один оператор, локальный доступ); экраны сигналов и результатов
обучения (приедут со своими изменениями); мобильная вёрстка; публичный хостинг.

## Capabilities

### New Capabilities

- `api/query-surface`: HTTP-поверхность только для чтения рыночных фактов —
  OpenAPI-контракт, чтение на момент времени, отсутствие пишущих путей.
- `api/operations-surface`: покрытие, реестр материализации и здоровье сбора как ресурсы
  для чтения.
- `web-console/market-views`: экраны рынка — обзор, детализация по паре «тип и локация»,
  графики цены, объёма, спреда и глубины.
- `web-console/operations-views`: экраны состояния — покрытие, материализация, расход
  ресурсов, различение «не наблюдалось» и «не материализовано, но восполнимо».

### Modified Capabilities

Нет — репозиторий не содержит спек.

## Impact

- **Новые проекты.** `src/presentation/EveTrader.Api` (minimal API, read-only) и фронтенд
  в `web/`. Стиль архитектуры остаётся **layered**: API — ещё одна presentation-поверхность
  рядом с CLI, домен и application не меняются.
- **Расхождение путей в наборе правил, третье по счёту.** `project-naming-and-setup.md`
  §4 указывает фронтенду `src/frontend/`, `typescript/react-and-components.md` и
  `typescript/workspace-and-i18n.md` — `web/`, а сосед hapy использует `frontend/`.
  Берём `web/`: команды гейта в правилах фронтенда написаны литерально «из `web/`» и при
  другом пути не выполнятся. Пункт добавляется в тот же issue наверх в `nova/meta/rules`,
  что и расхождение про layered.
- **Корень репозитория.** `project-naming-and-setup.md` §1 запрещает лок-файлы пакетных
  менеджеров в корне — `bun.lock` живёт в `web/`.
- **Гейт фронтенда** — три команды из `typescript/workspace-and-i18n.md` (`typecheck`,
  `lint`, `test`), каждая с нулевым выходом. Долгоживущие процессы (`dev`, `vite`,
  `--watch`, браузерные драйверы) из-под агента не запускаются —
  `process/agent-runtime-safety.md`.
- **i18n принимается как есть**, без локального отклонения: две локали (`ru`, `en`) для
  инструмента с одним оператором выглядят избыточно, но ретроспективное выдирание
  хардкода из готовых экранов дороже, чем ключ на строку сейчас.
- **Разделение процессов** означает вторую точку конфигурации пути к озеру и вторую точку
  наблюдаемости; и то и другое описывается по `process/config-resolution.md` и
  `observability/diagnostics.md`.
- **Зависимость по порядку**: реализуется после `add-market-observation-pipeline` и после
  появления первых сигналов. До этого предложение существует как зафиксированное решение,
  а не как работа в очереди.
