`ResourceUsageShould` и печатают команды оператора. Отчёт за интервал —
`ResourceUsageReport` по журналу покрытия и окну сырых страниц.

Замечено при замере: `observation.source.error_budget_remaining` не заполняется, пока
источник не пришлёт `X-ESI-Error-Limit-Remain`. На успешных ответах ESI его не прислал
ни разу — датчик молчит, и это не дефект метрики, а свойство источника.

## 3. Приёмка

- [x] 3.1 Прогнать приёмочный сценарий: перестроить признаки за материализованный интервал из сырья и сверить с записанными — проверка: совпадение полное для полных наблюдений, отчёт о покрытии без незапланированных пробелов; выбранный интервал содержит смену версии статических данных и досинхронизацию задним числом

Сценарий прогнан командой `accept` на озере из архива EVE Ref (15 сентября 2026, два
хаба, десять снимков, две версии статических данных) плюс дневная история за те же
сутки. Все три условия выполнены, `приёмка доказательна: да`.

- **Совпадение полное**: 1 176 760 признаков на шестнадцати наблюдениях, ноль
  расхождений. Четыре наблюдения из двадцати в сверку не входят — у них не закрылось
  окно подтверждения исчезновений; число печатается отдельной строкой отчёта.
- **Отчёт о покрытии без незапланированных пробелов**: разрывов цепочки наблюдений ноль.
- **Интервал содержит смену версии статических данных** (`sde-2026-08`, `sde-2026-09`)
  **и досинхронизацию задним числом** — 77 записей дневной истории за 15 сентября,
  импортированных 21-го.

Дорогой сюда найдены и исправлены две вещи, разбор в `design.md`:

1. `RegionTimeline.BookAt` сравнивал якорь и события по разным шкалам времени —
  перестановки, чей `issued` попадал внутрь интервала сбора предыдущего снимка,
  выпадали из восстановления навсегда. Исправлено, закреплено `WideWindowReplayShould`.
2. Цепочка наблюдений считалась по региону, а не по паре «регион и источник»:
  суточная история объявляла разрыв там, где данные полны.

Остаточное расхождение разобрано измерением на десяти настоящих снимках The Forge и
оказалось не дефектом, а возрастом вывода: последнее наблюдение цепочки невоспроизводимо
по построению. Норма `market-observation/book-features` дополнена этой оговоркой.
Разметка событий не тронута.

## 4. Команды оператора

- [x] 4.1 Реализовать команды `EveTrader.Cli`: запуск сбора, импорт интервала, отчёт о покрытии и материализации, осмотр фактов, реплей — проверка: каждая команда запускается и печатает непустой результат

Десять команд: `collect`, `import-history`, `import-orderbook`, `replay`, `accept`,
`coverage`, `materialization`, `facts`, `resource-usage`, `history-stats`. Каждая
запущена на настоящих данных, каждая напечатала непустой результат.

Живой сбор считает циклы и завершается сам — `--cycles` со значением по умолчанию один;
бесконечный режим (`--cycles 0`) включается явно. Иначе команду нельзя ни проверить, ни
прогнать под присмотром, а суточный прогон предсказуемее с объявленной границей.
