## MODIFIED Requirements

### Requirement: Признаки вычисляются в той же проходке, что события

Для каждой пары «тип предмета и локация», присутствующей в наблюдении, система SHALL
вычислять: лучшую цену покупки, лучшую цену продажи, спред, число ордеров с каждой
стороны, доступный объём в пределах заданных порогов отклонения от лучшей цены и число
ордеров в пределах тех же порогов. Вычисление SHALL происходить при разборе наблюдения,
без обратного запроса к хранилищу.

Число ордеров внутри порога — не то же, что число ордеров на стороне. У ходового типа в
хабе сотни ордеров в широком диапазоне цен, и конкуренцию создают только верхние;
величина, посчитанная по всей стороне, отвечает на другой вопрос. Выводить её задним
числом неоткуда: по записанным признакам состав стакана не восстановим, а восстановление
из событий на каждый шаг окна — та самая стоимость, ради ухода от которой признаки и
материализуются.

#### Scenario: Двусторонний стакан

- **WHEN** в наблюдении по паре «тип и локация» есть ордера покупки и продажи
- **THEN** вычислены лучшие цены обеих сторон, спред и глубина по заданным порогам
- **AND** по каждому порогу доступно число ордеров внутри него

#### Scenario: Односторонний стакан

- **WHEN** по паре «тип и локация» есть только ордера продажи
- **THEN** признаки продажи вычислены
- **AND** отсутствие стороны покупки записано как отсутствие, а не как нулевая цена

#### Scenario: Нет лучшей цены — нет и счётчиков

- **WHEN** по стороне нет ни одного ордера
- **THEN** ни глубина, ни число ордеров внутри порогов по этой стороне не записаны

### Requirement: Охват признаков задаётся отдельно от охвата наблюдения

Набор регионов и типов, для которых признаки материализуются, SHALL задаваться настройкой
независимо от охвата наблюдения. Сужение охвата признаков MUST NOT приводить к потере
данных, поскольку признаки восстановимы из сырья.

Охват MUST быть объявлен явно. Материализация признаков без объявленного охвата
запрещена: полный охват пар измерен в 770 ГиБ против ~62 ГиБ сырья, из которого он
выводится, — признак, который никто не читает, платить за себя не должен. Основанием для
охвата SHALL быть перечень пар, нужных правилам сигналов; догадка основанием не является.

#### Scenario: Признаки только по хабам при полном наблюдении

- **WHEN** наблюдение идёт по всем регионам, а охват признаков ограничен торговыми хабами
- **THEN** признаки материализованы только по хабам
- **AND** признаки по прочим регионам остаются вычислимыми задним числом

#### Scenario: Расширение охвата признаков

- **WHEN** охват признаков расширен на регион, по которому есть сырьё
- **THEN** признаки по этому региону построены из сырья за весь материализованный
  интервал

#### Scenario: Охват не объявлен

- **WHEN** запущена материализация признаков без объявленного охвата
- **THEN** прогон отклонён с указанием, что охват обязателен
