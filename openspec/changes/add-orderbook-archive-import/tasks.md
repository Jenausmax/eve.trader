## 3. Прогон окна

- [ ] 3.1 Прогнать конвертацию окна порциями по суткам с возможностью продолжить с обрыва — проверка: прерывание и перезапуск не дублируют факты и не теряют суток

  Механизм готов и проверен: integration-тест `WindowConversionShould` прерывает прогон и
  продолжает его с обрыва, а на настоящем архиве прогон по окну `2026-09-17 00:00…02:00`
  дважды продолжен с места обрыва без дублирования фактов и без потери снимков. **Сам
  прогон полного окна не выполнен**: это около 705 ГиБ загрузки и несколько суток счёта,
  то есть работа владельца, а не агента. Команда:

  ```bash
  dotnet run --project src/presentation/EveTrader.Cli -c Release -- \
    import-orderbook --lake <корень озера> \
    --from 2024-09-19 --to 2026-09-19 --sde <версия SDE>
  ```

  Обрыв любой природы лечится повторным запуском той же команды: точка продолжения
  выводится из журнала покрытия. Охват стоит сузить `--regions <id,...>` — см. §«Что
  вышло по объёму» в `design.md`.
