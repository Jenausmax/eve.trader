## Purpose

Признаки стакана — производный слой над событиями жизни ордеров: срез рынка по паре
«тип и локация» на момент наблюдения. Здесь же граница гарантии перестройки: что
конвейер обязан воспроизвести из сырья, а что воспроизвести не может и почему.

## MODIFIED Requirements

### Requirement: Признаки выводимы из сырья

Признаки MUST быть полностью выводимы из чекпойнтов и событий жизни ордеров. Система
SHALL позволять перевычислить признаки за произвольный материализованный интервал без
обращения к внешнему источнику.

Гарантия совпадения распространяется на полные наблюдения, чьё окно подтверждения
исчезновений закрылось внутри интервала. У последнего наблюдения цепочки подтверждать
нечем: следующего наблюдения ещё нет, и ордер, пропавший на этом такте, для конвейера
ещё жив. Записанные признаки взяты из самого наблюдения, перестроенные — из состава,
подтверждённого событиями; требовать их совпадения значило бы требовать вывода раньше,
чем набраны подтверждения. Цепочку рвёт и базовая линия: свёртка начинает с чистого
состояния, и накопленные до неё кандидаты подтверждения не получат.

Отчёт о перестройке MUST называть число наблюдений, оставленных вне сверки по этой
причине: сверка, из которой наблюдение выпало молча, неотличима от сошедшейся.

#### Scenario: Перестройка признаков

- **WHEN** набор признаков удалён и запрошено перевычисление за интервал
- **THEN** признаки восстановлены из сырья
- **AND** для полных наблюдений с закрытым окном подтверждения результат совпадает с удалённым

#### Scenario: Сверка признаков с восстановленным стаканом

- **WHEN** стакан восстановлен на время полного наблюдения и признаки вычислены заново
- **THEN** результат совпадает с сохранённым набором признаков

#### Scenario: Последнее наблюдение цепочки вне сверки

- **WHEN** запрошена перестройка признаков за интервал, последнее наблюдение которого ещё не подтверждено следующим
- **THEN** это наблюдение в сверку не входит
- **AND** отчёт называет число наблюдений с незакрытым окном
