# observability

Пусто по состоянию на первую волну сборки.

на сборку, имена метрик, dot.case-теги) — попало в список спорных: глобальная и
проектная версии расходятся по существу. Оно приедет второй волной, когда
владелец разведёт расхождения.

До тех пор ссылки вида `observability/diagnostics.md` из других правил ведут в
локальную версию потребителя.
